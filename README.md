
# WorkNStay

### Find Work. Find Stay.

WorkNStay is an India-focused platform designed to connect people looking for jobs with people looking for accommodation.

## Our Platform

### 1. WORK
- Job search by city and category
- Employer registration
- Job posting
- Job applications
- Candidate profiles

### 2. STAY
- Private room listings
- PG accommodation
- Flats and shared rooms
- City-based property search
- Contact property providers

## STAY Listing Policy

Three provider types are supported:

- Owner
- PG Operator
- Broker

Each provider must have a clearly visible identity label.

Verification badges will only be issued after actual checks.

## Safety and Security
- Report incorrect listings
- Admin approval and rejection
- Suspend suspicious accounts
- Mark unavailable properties
- Protect user information
